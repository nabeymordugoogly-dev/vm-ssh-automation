Описание

**Запускайте вашу виртуальную машину и подключайтесь к ней по SSH одной командой без лишних окон и задержек.**

Данный инструмент автоматизирует процесс работы с виртуальной машиной на базе Oracle VirtualBox. Вместо того чтобы открывать графический интерфейс VirtualBox, ждать загрузки системы и вручную вводить команды для подключения, вы просто вводите одну команду в терминале — и всё происходит автоматически.

## Возможности

- ✅ **Запуск в фоновом режиме** — виртуальная машина работает без графического интерфейса, потребляя меньше ресурсов компьютера.
- ✅ **Одна команда для запуска** — `RunVM` запускает ВМ и автоматически подключается по SSH.
- ✅ **Одна команда для выключения** — `offVM` корректно завершает работу ВМ.
- ✅ **Автоматическое ожидание загрузки** — скрипт ждёт, пока SSH-сервер станет доступен, и только затем подключается.
- ✅ **Безопасное соединение** — используется SSH-аутентификация по ключам.
- ✅ **Работа из любого места** — скрипты доступны из любой папки командной строки.
- ✅ **Проверка состояния ВМ** — скрипт определяет, запущена ли уже виртуальная машина.
- ✅ **Таймаут 60 секунд** — если SSH не поднялся, скрипт завершится с понятной диагностикой.

 ## Технологии

- **Oracle VirtualBox** — платформа для виртуализации.

- **Windows Batch Scripts** — для автоматизации процессов.

## Установка и настройка

### 1. Настройка SSH-доступа

Для автоматического подключения необходимо настроить SSH-аутентификацию по ключам.

#### Создание конфигурации SSH

Создайте файл `C:\Users\%USERNAME%\.ssh\config` (если он ещё не существует):

Host myserver
HostName 192.168.1.0 # ⚠️ Замените на IP-адрес вашей ВМ
User VMuser # ⚠️ Замените на ваше имя пользователя
IdentityFile ~/.ssh/id_ed25519
IdentitiesOnly yes
Port 22

> **Важно:** После каждой строки, кроме последней, должен быть отступ (пробел или табуляция). В конце файла должна быть пустая строка.

#### Генерация SSH-ключей (если их ещё нет)

В командной строке указываем: ssh-keygen -t ed25519 -C "комментарий ключа"
> где "комментарий ключа" это любая фраза позволяющая его найти среди других ключей

##### Копирование публичного ключа на сервер

В командной строке указываем: type C:\Users\%USERNAME%\.ssh\id_ed25519.pub | ssh VMuser@VM-ip "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
где:
> VMuser - пользователь виртуальной машины
> VM-ip - IP-адрес виртуальной машины

Проверяем подключение в командной строке: ssh myserver
> где myserver название Host из файла конфигурации.

**Чтобы запускать скрипты из любой папки командной строки, добавьте папку со скриптами в переменную окружения PATH.**

В командной строке (от имени администратора) выполните:  setx Path "%Path%;T:\Working_documents" /M
> где T:\Working_documents путь к вашей папке со скриптами.

Теперь вы можете запускать скрипты из любой папки

## Использование

Запуск виртуальной машины

В командной строке строке выполните: RunVM
Скрипт проверит, не запущена ли уже ВМ.
Если ВМ не запущена — запустит её в фоновом режиме.
Будет ожидать, пока SSH-сервер станет доступен (максимум 60 секунд).
Автоматически подключится по SSH.

Пример вывода:

[INFO] Starting virtual machine in background mode...
Waiting for VM "UbuntuLocal" to power on...
VM "UbuntuLocal" has been successfully started.
[OK] Virtual machine started successfully.
[INFO] Waiting for SSH service to become available...
[INFO] This may take a few moments...
[OK] SSH is ready!
[INFO] Establishing connection...
Welcome to Ubuntu 24.04 LTS (GNU/Linux 6.8.0-31-generic x86_64)

 * Documentation:  https://docs.ubuntu.com
 * Management:     https://landscape.canonical.com
 * Support:        https://ubuntu.com/pro

Last login: Fri Aug 7 14:03:12 2026 from 192.168.1.0
VMuser@ubuntu:~$

Выключение виртуальной машины

В командной строке выполните: offVM
Скрипт отправит сигнал корректного завершения работы (ACPI).
Виртуальная машина выключится так же, как при нажатии кнопки "Выключить" в системе.

Пример вывода:
[INFO] Shutting down virtual machine gracefully.
[OK] Shutdown signal sent.
[INFO] The VM will shut down gracefully, may take a few seconds.

## Устранение проблем

1. ssh myserver запрашивает пароль.
> Файлы в папке C:\Users\%USERNAME%\.ssh должны принадлежать только вашему пользователю.
> Убедитесь, что в свойствах папки и файлов нет группы Users или Authenticated Users.
> Проверьте, что ключ добавлен на сервер cat ~/.ssh/authorized_keys
> Попробуйте подключиться с явным указанием ключа: ssh -i C:\Users\%USERNAME%\.ssh\id_ed25519 VMuser@VM-ip

2. Таймаут при подключении (SSH не доступен).
> Проверьте, запущена ли ВМ: "C:\Program Files\Oracle\VirtualBox\VBoxManage.exe" list runningvms
> Проверьте доступность ВМ по сети: ping 192.168.1.0
> Проверьте, запущен ли SSH-сервер на ВМ: sudo systemctl status ssh

3. Виртуальная машина не запускается.
>  Проверьте, что ВМ с правильным именем существует: "C:\Program Files\Oracle\VirtualBox\VBoxManage.exe" list vms
> Если ВМ в состоянии "locked", сбросьте её: "C:\Program Files\Oracle\VirtualBox\VBoxManage.exe" controlvm "UbuntuLocal" poweroff

4. Скрипты не запускаются из любой папки.
> Проверьте, что папка добавлена в PATH: echo %Path% | findstr "Working_documents"

## Преимущества 

> Экономия времени — больше не нужно открывать VirtualBox, ждать загрузки и вручную вводить команды.
> Снижение нагрузки на систему — виртуальная машина работает в фоновом режиме без графического интерфейса.
> Простота использования — всего две команды для полного управления: RunVM и offVM.
> Надёжность — автоматическая проверка состояния ВМ и таймаут при недоступности SSH.
> Безопасность — используется SSH-аутентификация по ключам вместо пароля.
> Универсальность — скрипты доступны из любой папки благодаря настройке PATH.

## Требования

> Windows 10/11.
> Oracle VirtualBox 7.0 или новее.
> OpenSSH (встроен в Windows 10/11).
> Виртуальная машина с настроенным SSH-сервером.
> Права на выполнение batch-скриптов.
